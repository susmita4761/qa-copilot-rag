# BUG-001: Lockout not triggered after 5 failed logins

**Status:** Resolved
**Severity:** High
**Module:** Login / Authentication

## Description
Entered wrong password 8 times in a row for the same account. Account was never locked, and no lockout message was shown. Expected lockout after the 5th attempt per US-101.

## Steps to Reproduce
1. Go to login page.
2. Enter valid email with wrong password.
3. Repeat 8 times within 2 minutes.

## Expected
Account locks for 15 minutes after the 5th failed attempt, with a clear error message.

## Actual
No lockout occurred even after 8 attempts.

## Root Cause
Failed-attempt counter was being reset on every page refresh instead of persisting server-side per account.

## Fix
Moved failed-attempt tracking to a server-side counter keyed by account ID with a 10-minute rolling window.
